# To-Do List App

A simple and interactive To-Do List application built with HTML, CSS, and JavaScript. This project helped me practice JavaScript fundamentals and DOM manipulation.

## Features
- Add new tasks
- View tasks in a clean interface
- Manage your daily tasks

## Technologies Used
- HTML5
- CSS3
- JavaScript

## What I Learned
- DOM manipulation
- JavaScript event handling
- Working with user input
- Updating webpage content dynamically

## Project Structure

- `index.css` — Styling and layout
- `script.js` — Application functionality
